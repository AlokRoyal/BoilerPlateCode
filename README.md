# p5.js Game Starter

A minimal browser game scaffold using p5.js and p5.play. It creates a 600 × 600 canvas with an empty draw loop for building a sketch.

## Stack

- HTML5 (`index.html`)
- JavaScript (`sketch.js`)
- p5.js, p5.dom, p5.sound, and p5.play scripts loaded from `lib/`
- CSS loaded from `CSS/style.css`

## Run

Open `index.html` in a browser. Keep the `lib/` and `CSS/` directories alongside it. Add initialization to `setup()` and frame updates or drawing to `draw()` in `sketch.js`.
